# CaissePro v2

Clean starter for CaissePro: a multi-tenant SaaS POS platform for West Africa.

## Stack

- Next.js
- Tailwind CSS
- Supabase
- Vercel

## Setup

1. Install dependencies:

```bash
npm install
```

2. Copy `.env.example` to `.env.local` and add Supabase keys.

3. Run locally:

```bash
npm run dev
```

## Deploy

Push to GitHub, then import the repository into Vercel.
